# Tools Used«

## Wireshark
Used to analyze network traffic, identify suspicious conversations and investigate RDP traffic.

## NetworkMiner
Used to extract files, credentials and network artifacts from the PCAP.

## Volatility 3
Used for memory analysis with plugins including:

- `windows.info`
- `windows.netscan`
- `windows.malfind`
- `windows.pstree`
- `windows.cmdline`

## Autopsy
Used to analyze E01 disk images and Windows forensic artifacts.

## Eric Zimmerman's Tools
Used to analyze Windows Event Logs, registry data, MFT-related artifacts and timeline information.

## Arsenal Image Mounter
Used to mount forensic disk images as local disks.

## FLOSS
Used to recover obfuscated strings from malware and memory dumps.

## capa
Used to analyze shellcode capabilities.

## ClamAV
Used to identify Meterpreter payloads extracted from memory.

## CyberChef
Used to decode Base64-encoded payloads.

## Joe Sandbox
Used for dynamic malware analysis and MITRE ATT&CK behavior mapping.

## SIFT Workstation
Used as the primary DFIR analysis environment.

## REMnux
Used as the malware-analysis environment.
